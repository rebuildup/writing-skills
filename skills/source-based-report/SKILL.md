# Source-Based Report

授業・配布資料・指定文献に基づくレポートを、提出条件と実際の筆記作業に合う文章・図・式へ変換する。対象は資料依存の学習レポートや要点整理。独自実験の研究論文、一般的な論文作法、出典を伴わない創作は扱わない。

`writing-discipline` を基盤とし、文章の自然さは必要に応じて `natural-japanese` に委ねる。この Skill は **資料への忠実さ、内容の選択、式・図の組み込み、紙面容量、筆記中の調整** だけを追加する。

## Scope and inputs

着手前に課題文、対象資料、提出様式、評価条件、参考文献の扱いを確認する。次を区別しておく。

- 必須: 対象回・論点、行数の下限／減点境界、図の数、提出形式、締切など。
- 目安: 文字数、構成比、推奨図、書式。目安を必須条件へ昇格しない。
- 実測: 1行に書ける文字数、本人が書き終えた行数、図の実際の高さ。

課題に AI 利用や引用の制限があれば従う。資料に存在しない条件や教員の意図を推定で補わない。

## Workflow

1. **根拠を読む。** 課題の対象範囲と資料の用語・定義・記号・例題・図の向きを確認する。PDFの抽出テキストで上線・数式・図が欠落する場合は原ページを確認する。
2. **内容を選ぶ。** 各資料の主要論点を列挙し、定義だけでなく重要な式・手順・具体例を選ぶ。資料にない内容は「追加調査」として分離する。量を増やすためだけの繰り返しは選ばない。
3. **本文へ組み込む。** 見出し単位で自然に改行し、本文は自動折り返しにする。短い数式は意味・導出を説明する文章に含める。複数段の導出や視線を独立させる価値のある式だけを別行にする。
4. **図を配置する。** 図が狭幅で十分読めるなら紙面の一部に差し込み、隣の領域でも本文の流れを続ける。図の横を専用の解説欄や無意味な余白にしない。図は本文と重複する説明を省くために使い、参照可能な図番号・必要なラベルを付ける。
5. **紙面を見積もる。** 1行の実測容量を使って節ごとの行数を見積もる。長い段落の自動折り返し、見出し改行、図の高さ、横の文章、参考文献を別々に計算する。横並びの図と本文は合計ではなく **高いほうの必要行数** が紙面を占める。デジタル版がA4・1ページでも手書きの行数達成とはみなさない。
6. **筆記中に再配分する。** 実際に書いた箇所と行数の報告を受けたら、そのペースで残りを再見積もりする。書き終えた内容を書き直す前に、未筆記部分だけで下限と参考文献の余白を満たせるか調整する。足りなければ資料に根拠のある新しい説明・条件・例を補い、余るなら重複から削る。

## Decision rules

- **資料準拠:** 授業資料の記号・語彙・表現と矛盾する一般知識への言い換えをしない。新しい例は資料の記載と区別し、等価性・計算結果を検証する。
- **内容密度:** 各文について「新しい事実、意味、操作、根拠のどれを与えるか」を確認する。説明が長くても既知内容の言い直しなら削る。式を減らすのではなく、式の周囲の不要な前置きを減らす。
- **段落と式:** 見出しや意味の転換では改行する。短い式のために「次のようになる。」と述べて毎回1行消費しない。一方、複雑な展開や比較では独立した式・表を使ってよい。
- **調査補足:** 授業範囲と関係があるが資料だけでは説明されない **新しい論点** を取り出す。外部資料で直接確認した要点を選び、短い原文引用は正確に括って出典を示す。要約と引用を混同せず、出典不明の著者・論文名・URLを作らない。
- **分量:** 行数・文字数は最低条件と上限・書く作業量の両面で評価する。全角相当の概算値だけで確定させず、実際の筆記進捗と罫線数で修正する。図の大きさや式の筆記幅は本文の文字数から推定しきれない。
- **提出前:** 完成稿を知らない読者として読み、指示条件、定義と記号、計算・図の整合、引用先、本文と図の自然な流れ、最後の参考文献までの行数を確認する。ファイル名・提出先は課題で確認した値だけを使う。

## Failure modes and counterexamples

- **悪い:** 「排他的論理和は次のようになる。」の次行に短い式だけ置く。**よい:** 「出力1の行から最小項を作ると、標準積和式は `Z=ĀB+AB̄` となる。」と導出の説明に含める。**例外:** 数段の式変形は改行したほうが検算しやすい。
- **悪い:** 縦長の図を置き、その横に図専用の説明を機械的に並べる。**よい:** 図を左側に差し込み、右側には同じ節の本文を自然に流す。**例外:** 図が小さくなると読めない、または指定書式が全面図を要求するなら全幅にする。
- **悪い:** 「40行分」と称して全体文字数を40で割る。**よい:** 節ごとの折り返し、強制改行、図と横組み、参考文献の領域を見積もり、実際の筆記行数で更新する。
- **悪い:** 既存説明を長く言い換えて分量を埋める。**よい:** 資料と関係のある、未説明の論点・条件・具体例を補う。新情報がなければ文量だけを増やさない。

## Verify

- 資料にある専門用語・数式・図示を正しく使い、資料由来と外部調査を分離できているか。
- 追加した文章は読者の理解や課題達成に実質的に寄与するか。
- 文字数見積と実際の紙面・筆記進捗を混同せず、必須行数と参考文献の空間を守るか。
- 言い換えで内容を薄めず、図・式・段落が互いに補完しているか。
